## 🤔 为什么做这个库？

写页面时经常需要一个小效果：按钮 hover、loading 动画、卡片浮起…… 每次都去翻以前的项目或重新谷歌，太浪费时间。

这个库把高频效果全部用**纯 CSS** 实现，每个效果都是独立的 HTML + CSS 片段，**复制粘贴即用，零依赖**，不需要引入任何库。

## 🚀 使用方式

1. 打开 **[在线演示站](https://anonymousleejj.github.io/pure-css-effects/)**
2. 找到喜欢的效果，点「📋 复制代码」
3. 粘贴到你的项目里，改改颜色就是自己的了

或直接浏览 [effects.json](effects.json) 获取全部源码。
